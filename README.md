# 📚 Aventures Infinies

Une application React interactive avec **10 histoires magiques pour enfants**!

🎮 [Joue en ligne](https://codesandbox.io/s/github/TONNOM/aventures-infinies)

## ✨ Caractéristiques

- ✅ **10 histoires complètes** pour enfants (8-14 ans)
- ✅ **45+ fins différentes** - chaque choix compte!
- ✅ **Narration vocale française** avec Web Speech API
- ✅ **Thème sombre/clair** adaptatif
- ✅ **Sauvegarde locale** automatique
- ✅ **Système de points** et achievements
- ✅ **100% gratuit** et sans publicités
- ✅ **Responsive** (mobile, tablet, desktop)

## 🚀 Démarrage Rapide

### Prérequis
- Node.js 14+ ([Télécharger](https://nodejs.org/))

### Installation (3 étapes!)

```bash
# 1. Installer les dépendances
npm install

# 2. Lancer l'app
npm start

# 3. Jouer! 🎮
# L'app s'ouvre sur http://localhost:3000
```

1. 📖 **Sélectionne une histoire**
2. 🎧 **Clique "Écouter"** (optionnel)
